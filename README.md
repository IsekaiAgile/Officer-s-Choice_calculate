# Officer's-Choice専用計算機
## 概要
「異世界アジャイルカードゲーム」で作成した対戦型カードゲーム『Officer's-Choice』専用の計算機となります。
## 操作説明
スマートフォン・タブレットで当アプリを開き、テーブルの横に置きます。

左側と右側のそれぞれで計算機を使用することができます。



ゲーム開始時、プロダクトカードを選択しますが、

それをアプリ側でランダムに選択してくれます。

カードの裏面をタップ→「ランダムにカードを選びますか？」に「はい」を選択

で、今回のゲームで使用するプロダクトカードを選んでくれます。

また、既に選んでいた場合でも、「いいえ」を選択すると

プロダクトカードの種類が出てくれるため、既に選んでいたものと同じものを選んでプレイしてください。

（得点計算の際に使用します）



表になったカードをタップすると、そのプロダクトカードの説明を見ることができます。



上にある「要件」「製造」「品質」の上・下マークを押下すると、

数をカウントすることができます。



真ん中付近にある「↑」マークを押下すると「↓」マークになります。

（もう一度押すと戻ります）

「↑」マークの間はコストを、

「↓」マークの間は特典をそれぞれ増減することができるようになります。



コストと特典の間にある矢印はそれぞれ、+10、+1、-1、-10となっております。



入力後、ゲーム終了時に一番下に記載されている「利益」が高いほうが勝利となります。



「RESET」ボタンを押すとリセットできます。

「CREDIT」ボタンはクレジットが表示されます。
